# Filing & Payment Tracker – Power Apps POC Setup

This bundle is a build-ready setup guide for a Power Apps Canvas App.

IMPORTANT
- This is NOT an .msapp file and cannot be imported as a finished Canvas App from the Power Apps portal.
- Power Apps Studio does not accept arbitrary TXT/YAML as a finished-app import.
- Use the included files to create the app quickly and consistently.
- The two notification buttons are prepared with placeholder Power Automate flow names. Until flows are connected, use the POC formulas in 05_Button_Formulas.txt.

Recommended app:
- Canvas app
- Tablet/Desktop layout
- Responsive containers
- Screen name: scrFilingTracker

Files:
01_App_OnStart.txt              Theme variables
02_Control_Hierarchy.txt        Exact control names and grouping
03_Fields_and_Items.txt         All 16 fields and dropdown values
04_Layout_and_Style.txt         Layout dimensions and styling
05_Button_Formulas.txt          POC and future flow formulas
06_Validation_Formulas.txt      Conditional enable/disable logic
07_Build_Order.txt              Step-by-step build sequence
